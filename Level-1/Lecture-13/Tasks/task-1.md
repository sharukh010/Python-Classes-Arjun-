# Function Practice 
Create functions for the following 
1. Create a function to perform subtraction `sub(num1,num2)`
2. Create a function to perform multiplication `multiply(num1,num2)`
3. Create a function to perform division `divide(num1,num2)`
- whenever num2 is 0 return None 
4. Create a function to perform power `power(num1,num2)`
Note: all the function should return the result 
Sample Input: 
```python
print(sub(20,10))
print(multiply(5,2))
print(divide(10,2))
print(divide(10,0))
print(power(2,3))
```
Sample Output: 
```text
10
10
5
None
8
```
