Logical Operators (OR,XOR,AND,NOT)
1. OR: 
A = I need Samosa 
B = I need Panipuri 
A or B = I need Samosa or Panipuri 
OR means any one of them or both of them 
        A              B            A OR B 
        True          False         True (satisfaction)
        False         True          True 
        False         False         False 
        True          True          True 
2. XOR (Exclusive OR)
XOR means either this or that but not both 
A = I need Play Station 
B = I need to donate to the Poor 
        A              B             A XOR B 
      True             False         True 
      False            True          True 
      False            False         False 
      True             True          False ( bought playstation and donated it to the poor)
3. AND 
A = I need Samosa 
B = I need Panipuri 
A and B = I need Samosa and Panipuri 
AND means both of them 
       A            B            A AND B 
      True         False         False 
      False        True          False 
      False        False         False 
      True         True          True 

4. NOT - it is applied on single condition 
A = I need Samosa 

    A         NOT A 
    True      False 
    False     True
